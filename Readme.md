\# Python ATM Simulator



A lightweight, object-oriented terminal ATM simulator built in Python.



\## Features

\* \*\*Deposit:\*\* Add funds to your account balance.

\* \*\*Withdrawal:\*\* Withdraw funds with built-in balance checks to prevent overdrawing.

\* \*\*Balance Inquiry:\*\* Check your current available balance anytime.

\* \*\*Interactive Menu:\*\* Smooth loop interface for continuous transactions until exit.



\## How to Run

1\. Make sure you have Python installed.

2\. Run the script from your terminal:

&#x20;  ```bash

&#x20;  python ATM.py
